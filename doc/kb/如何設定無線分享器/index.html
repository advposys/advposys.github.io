📡 如何設定無線分享器?

採購無線分享器，重要的是要買背後有網路孔的機器，為了是跟印單機和貼紙機連接

各廠牌的設定畫面不同 但原理流程大同小異

幾個重點如下

1.規劃網路IP分配

無線分享器、平板電腦、印單機、貼紙機都要有自己的獨立IP，假設我們有三台平板，兩台印單機，一台貼紙機，範例如下

無線分享器：192.168.1.1

平板電腦一:  192.168.1.11

平板電腦二:  192.168.1.12

平板電腦三:  192.168.1.13  (以後如有擴充平板設備就從192.168.1.14往下分配 )

印單機一:192.168.1.21

印單機二:192.168.1.22

貼紙機:192.168.1.31(以後如要加一台貼紙機就是192.168.1.32 )

2.將DHCP改到192.168.1.100-192.168.1.110 ，或不要自動分配

每個設備都已經確實依照上表設上IP，請將DHCP改到192.168.1.100-192.168.1.110 ，或將 DHCP 關掉

3.SSID命名英文+數字

SSID 不要使用預設值，不要取名譬如 ASUS ，TPLink 等等系統的預設，避免和其他鄰居的機器重複造成系統混淆，可以是店的英文名稱譬如advpos213   ttcafee351 。

4.要設定密碼

不要為了方便不設密碼，設了密碼可以避免不相干外部連線干擾，增加網路穩定性。

依上述原則設定無線分享器，就可增加網路的穩定性，不會再有常常連不上，網路時好時壞的情形。
