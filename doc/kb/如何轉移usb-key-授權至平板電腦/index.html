如何轉移USB KEY 授權至平板電腦?

請注意:一支Keypro只能轉移一次授權

1.先不要插入USB Key ,然後進入先用POS系統 此時系統為試用狀態

2.按下設定->註冊

3.按下平板方案

4.插上USB Key Pro

5.請閱讀注意事項後打勾 然後進行授權

6.記下註冊碼,日後該台平板如回復原廠預設值,可以再次輸入使用,請注意!!!此註冊碼只針對這台平板有效

7.註冊碼是由每台平板的硬體序號演算出來的 每台都不一樣,如果平板送修 刷新韌體 更改機 號等動作 更換導致序號改變 註冊碼將無法使用 ,必須重新購買授權
